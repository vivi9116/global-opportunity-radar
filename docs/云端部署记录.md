# 已验证的云端部署

核对时间：2026-11-15，新加坡时间。

- 公开仓库：https://github.com/vivi9116/global-opportunity-radar
- 在线监控台：https://vivi9116.github.io/global-opportunity-radar/
- 首次完整任务：https://github.com/vivi9116/global-opportunity-radar/actions/runs/43614476962
- GitHub API最终结论：completed / success；测试、采集、数据提交、Pages快照上传和网页发布步骤均成功。
- 19项Python测试与Node折叠排版/内容转义检查在真实Ubuntu运行器通过。
- 实测首页、app.js、styles.css、data/latest.json、data/source_health.json均返回HTTP200；公开数据标记environment=github-actions，并带有对应run_id。

第一轮云端保留330条采集记录、19条单独标记的参考项目。配置30个平台、56个社区或栏目；26个平台响应有效，23个平台有本轮匹配。有效响应并不等于核验成交，数量也不是全球全部内容。平台、社区/栏目、历史页面数量没有混算。

本轮没有成功采集的入口：BHW RSS返回403；CNode公开入口404；Side Hustle Nation返回HTML而非RSS；Warrior Forum返回HTTP200但正文0字节。Reddit第一个社区有内容，第二个请求429，后续16个社区遵守同一来源暂停期而未发送请求。具体原因、URL和时间均在source_health.json保留，没有据此捏造封号、封IP或地区限制。

Upwork、Fiverr、X、私密Facebook/Telegram、付费选品内部数据与DLsite列为未接入。没有向未接入的来源发送请求，也没有把它们算成抓取成功。登录站、私密群与付费接口需要合适授权，不能凭列出平台名称宣布已覆盖。

工作流计划在每小时UTC的11、31、51分钟触发，标准公开运行器执行。首轮已验证，后续仍可能排队、延迟、因源站变化或账号策略失败；每轮如实更新状态。Pages压缩产物只保留1天，不使用收费API。

本机服务只同步公开云端结果，每5分钟检查一次，不再定时访问各业务平台；页面也是每5分钟或用户手动刷新时读取快照。没有启动或操控浏览器。旧程序已清理，有用旧HTML资料已保留为参考与私有档案。原始响应、SQLite、账号信息和私有档案未上传到公开仓库。
